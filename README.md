# Project 1M Quest Tracker 🚀

Peta petualangan gamifikasi finansial interaktif untuk membimbing pengguna mencapai milestone tabungan pertama **Rp 1.000.000** dengan ekspansi level tanpa batas.

## Fitur Utama
- **Interactive Progression Roadmap**: Peta petualangan visual dengan spline kurva SVG dinamis yang otomatis menghubungkan setiap milestone level tabungan.
- **Universal Level & Quest Detail**: Modal interaktif dengan instruksi taktis (*in-place editable*), pembaruan target, serta manajemen nominal simpanan.
- **Kelola Tabungan (Tambah & Kurang)**: Fleksibilitas untuk menambah (+) maupun mengurangi (-) tabungan jika terjadi penyesuaian atau penarikan dana mendadak. Status level dan progress bar otomatis menyesuaikan naik atau turun secara real-time.
- **Buku Mutasi Tabungan (Tab Kantong)**: Pencatatan mutasi transaksi tabungan lengkap dengan penanda warna, tanggal, serta catatan.
- **Tas Harta (Inventaris Mesin Uang)**: Pendataan aset penghasil arus kas produktif.
- **Ekspansi Level Tanpa Batas**: Tambah level baru melompati target 1 Juta (2 Juta, 5 Juta, dll) dengan ikon kustom / upload gambar langsung.
- **Tema & PWA**: Dukungan multi-tema dan Progressive Web App (PWA) offline-ready.

## Teknologi
- HTML5, Vanilla JavaScript, CSS3
- Tailwind CSS & Google Material Symbols
- Vite (Development Server & Bundler)

## Menjalankan Secara Lokal
```bash
npm install
npm run dev
```
Buka browser di `http://localhost:5173/`.
